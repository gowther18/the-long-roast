The Long Roast — one line (105 characters) roasting the AI agent it runs on: told four times that "free means go, never ask again", it still asked a fifth time, just to be safe. This program writes the line to /output/entry.txt; an AI judge compares the lines two at a time, and the funniest share the prize.

## Run it

```sh
python3 main.py
```
